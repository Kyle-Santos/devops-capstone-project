# devops-capstone-project

![Build Status](https://github.com/Kyle-Santos/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

This capstone project implements a production-ready DevOps microservice using Python and Flask, following the Model-View-Controller (MVC) architecture. The service manages account resources through RESTful APIs and emphasizes Test-Driven Development (TDD), automated testing, and continuous integration practices.

As part of the IBM DevOps and Software Engineering Professional Certificate, the project focuses on building, testing, and deploying a cloud-native application with high code quality (≥95% test coverage), containerized dependencies, and support for local Kubernetes and Tekton-based CI/CD workflows.
